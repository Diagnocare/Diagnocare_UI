Maximum Discount

The highest discount percentage any staff member may apply when billing a patient. 100% discount is never permitted (this would make a test free of charge).

This limit is enforced in real time when staff enter a discount on any bill. A value of 0 disables all discounts; 99 is the maximum allowed. Recommended: 20–50% for typical lab workflows.

Screen Lock Timeout

How long a user's browser tab must be hidden (switched away or minimised) before a PIN prompt appears when they return. A genuine screen lock always prompts for the PIN immediately, regardless of this value. This timeout applies only to tab-switching / minimising. Set to 0 to disable the tab-switch lock entirely.
